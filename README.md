# Stonecutter downloads

Stonecutter is a Minecraft Java Edition launcher: Vanilla, Forge, NeoForge, Fabric and Quilt, mods, resource packs, shader packs, modpacks, skins and capes. It does not include Minecraft. You need your own copy of the game.

This repository only hosts the downloads. Get the latest from the [Releases page](https://github.com/nnnunezr/stonecutter-downloads/releases/latest).

Stonecutter is an independent project. It is not made by, affiliated with or endorsed by Mojang or Microsoft. It includes some textures from Minecraft: Java Edition, which belong to Mojang.
